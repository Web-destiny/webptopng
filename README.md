# Пиксель

Статический конвертер изображений в PNG. Файлы обрабатываются только в браузере и не отправляются на сервер. Поддерживаются форматы, которые умеет открывать браузер; анимированные изображения сохраняются как один кадр.

Откройте `index.html` в браузере или опубликуйте содержимое репозитория на GitHub Pages: Settings → Pages → Deploy from a branch → выберите ветку и папку `/ (root)`.
